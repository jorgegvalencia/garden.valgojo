Durante años diseñé pensando en la pantalla entera. Las container queries cambian la pregunta: ya no es "¿cómo de ancha es la ventana?", sino "¿cuánto sitio me han dado?".

## El cambio de mentalidad

Un componente que sabe medirse a sí mismo se puede mover a una barra lateral, a un modal o a una rejilla sin tocar su CSS.

```css
.card-wrapper { container-type: inline-size; }

@container (min-width: 28rem) {
  .card { grid-template-columns: 8rem 1fr; }
}
```

### Unidades de contenedor

`cqi` y `cqb` son a los contenedores lo que `vw` y `vh` a la ventana. Sirven para tipografía fluida dentro de una tarjeta.

## Cuándo no usarlas

- Para el esqueleto de la página siguen mandando las media queries.
- Si el contenedor depende del tamaño de sus hijos, aparece un bucle y el navegador lo corta.
